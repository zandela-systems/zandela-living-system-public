# Demonstrations

This directory will contain public demonstrations of ZANDELA / LIVING SYSTEM as they pass publication review.

Planned demonstrations include:
- a governed project-state transition;
- evidence-backed case-file rendering;
- failure/correction preservation;
- bounded agent execution;
- human-versus-machine checkpoint parity;
- public-safe relationship exploration.

Demonstrations are intended to show actual system behavior, not speculative capability claims.
