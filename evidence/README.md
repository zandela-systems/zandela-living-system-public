# Public Evidence

This directory is reserved for **publication-safe evidence artifacts**.

Examples may include:
- screenshots of public interfaces;
- sanitized validator summaries;
- architecture diagrams;
- demonstration receipts;
- selected test evidence;
- public-safe before/after state transitions.

Artifacts are included only when they can be published without exposing credentials, private evidence, customer data, internal prompts, or proprietary implementation details.

Absence of an artifact here does not imply absence of private evidence in the canonical system.
